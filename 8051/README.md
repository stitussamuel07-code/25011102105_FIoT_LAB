# 8051 Experiments

Platform: AT89S52 (8051) · Keil µVision (C51) · Proteus

| Folder | Experiment |
|---|---|
| [CAT2](CAT2/) | LED Blinking |
| [CAT3](CAT3/) | Key-Controlled LED Chaser |
| [CAT4](CAT4/) | Keypad, 7-Segment Display and LED Patterns |
| [CAT5](CAT5/) | Timer 0 Interrupt LED Blink |
| [CAT6](CAT6/) | UART and Keypad Mode Control |
| [CAT7](CAT7/) | LCD Display (16x2, 4-bit mode) |

Each folder has a `README.md` (with the circuit diagram), `circuit.png`, the source code, `STARTUP.A51`, the Keil `.uvproj` and the compiled `.hex` in `Objects/`.
