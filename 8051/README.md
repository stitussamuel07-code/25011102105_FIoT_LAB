# 8051 Experiments

Platform: AT89S52 (8051) · Keil µVision (C51) · Proteus

| Folder | Experiment |
|---|---|
| [CAT1](CAT1/) | LED Blinking |
| [CAT2](CAT2/) | Key-Controlled LED Chaser |
| [CAT3](CAT3/) | Keypad, 7-Segment Display and LED Patterns |
| [CAT4](CAT4/) | Timer 0 Interrupt LED Blink |
| [CAT5](CAT5/) | UART and Keypad Mode Control (5a, 5b, 5c) |
| [CAT6](CAT6/) | LCD Display (16x2, 4-bit mode) |

Each folder has a `README.md`, `circuit.png`, the source code, the Keil project and the compiled `.hex`.
