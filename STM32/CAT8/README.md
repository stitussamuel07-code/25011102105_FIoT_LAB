# CAT8 – GPIO Bring-Up on STM32F103C8

**Experiment:** CONTINUOUS ASSESSMENT 8 – GPIO output and input on the STM32F103C8

| Task | Folder | Project | What it does |
|---|---|---|---|
| 8A | [CAT8A](CAT8A/) | `Ex1F103LEDBlink` | Blinks an LED using GPIO output and `HAL_Delay()` |
| 8B | [CAT8B](CAT8B/) | `switch` | Controls an LED with a switch using GPIO input |

Both projects are created with STM32CubeMX (`.ioc`) and use the STM32 HAL library.
